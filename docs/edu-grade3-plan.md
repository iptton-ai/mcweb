# 三年级课程融入计划（构思稿 v1）

> 目标：把深圳小学三年级 14 本课本（语/数/英/道法/科学/音乐/美术，上下册）的学习内容，
> 变成这个体素游戏里**可玩的机制**，而不是「游戏里贴题目」。
> 原则：每个玩法必须回答「课本里的哪个知识点 → 游戏里的哪个已有系统 → 孩子玩起来像在玩，不像在考试」。

## 0. 核心设计理念

- **知识即资源，解题即生产**：把课本知识点做成游戏内的「原料/图纸/钥匙」，孩子为了推进游戏（建房子、开产线、打怪）自然要动用课内知识。
- **复用已有引擎能力，少造轮子**：红石（逻辑）、动力组（流水线）、活塞/电梯（物理机关）、AI 助手（出题/NPC 对话/批改）、合成配方（数学）、BGM（音乐）、录像（展示作业）——每个学科都能挂到现成系统上。
- **MDA 视角**：机制来自课本，动态来自沙盒自由度，美学体验主打 **Discovery（探索）+ Expression（创造）+ Challenge（小挑战）**，正对这个年龄段。

## 1. 分学科玩法构思

### 1.1 数学（北师大版）★ 最容易引擎化
三年级核心：乘除法、分数初步、时分秒/千米/吨、周长与面积、图形运动（平移旋转）、搭配问题。

| 知识点 | 玩法 | 挂载系统 |
|---|---|---|
| 乘除法 | **密码门**：红石锁 + 数字 keypad 方块，门牌写「7×8」，按对才开（孩子房/宝箱房） | 红石 + 门 |
| 分数 | **分数熔炉**：配方显示「½ 块蛋糕 = 需先做 2 份 ÷ 切 4 块取 2」，合成链里嵌分数比较 | RECIPES 合成表 |
| 周长/面积 | **地皮拍卖**：NPC 村长给出地块，「用栅栏围一块周长 24 的地，越大越好」→ 面积vs周长权衡 | 建造 + AI 助手判定 |
| 时分秒 | **昼夜任务**：任务限时（「日落前送到」，日落 = 游戏内时刻可读），读钟面方块 | daynight + 任务系统 |
| 千米/吨 | **电梯限重 / 传送带运量**：平台载重以「吨」计，超载悬停——估算与单位换算 | L2 滑轮电梯（应力已有） |
| 图形运动 | **活塞平移画**：用活塞推动像素马赛克，观察平移；红石火把时钟驱动「旋转木马」 | 活塞 + 观察者 |
| 搭配问题 | **服装系统**：给角色穿戴 2 帽 × 3 衣，解锁「搭配大师」成就，AI 助手问「共有几种？」 | 轻量新增 |

### 1.2 语文（统编版）
核心：生字词、古诗、阅读理解、习作（观察日记）。

- **识字矿石**：挖矿会挖到「字卡方块」，收集进「识字图鉴」（复用 E 背包 + 图鉴 UI）；同一课的生字集齐可在工作台合成「课文卷轴」= 开启对应剧情关。
- **古诗密境**：按古诗内容生成的场景（《望天门山》→ 峡谷水门地形），场景里藏着缺字碑，孩子补对字（选择/手写输入）石门开启，BGM 切换为诗吟诵氛围曲（音乐组联动）。
- **观察日记 = 施工录像**：语文习作「写观察日记」→ 游戏里种一颗种子延时录像（已有录像系统）+ AI 助手引导口述成文，导出图片/视频配文字。习作作业 gamified。

### 1.3 英语（沪教版）
核心：单词、简单对话、字母。

- **English NPC 商人**：村民只说英语，「I'd like three apples, please.」孩子要点对数量与物品才完成交易（听力可配 TTS 音频）。答对得绿宝石。
- **单词陷阱**：苦力怕变「Spelling Bee」蜂群怪：飞过来头上顶中文（如「桥」），孩子必须在物品栏选出「BRIDGE」方块扔给它，否则蜇一下（轻惩罚）。教材单元词表直接入题库。
- **字母合成**：合成面板英文配方名，收集字母方块拼单词开宝箱（拼读自然嵌入）。

### 1.4 科学（教科版）★ 与沙盒天然契合
三年级：水、空气、天气、动植物、材料、溶解。

- **水循环地图**：加热（熔炉/岩浆）→ 蒸汽粒子 → 高空云（已有云系统）→ 雨天（可加天气）→ 收集雨水，「蒸发-凝结-降水」整条链亲手搭一遍。
- **空气占据空间**：水下建筑倒扣玻璃杯，气泡不逃逸 = 隐藏气室关卡（氧气条联动：在气室里可呼吸！）。
- **溶解实验台**：新方块「实验杯」，投糖/沙/油看是否溶解，记录进「科学笔记」（任务日志）。
- **动植物图鉴**：已有的猪/牛/绵羊/苹果树扩展「饲养与生长」：喂食、生长阶段、生命周期记录（观察日记联动语文）。
- **材料性质**：已有的硬度/工具等级体系直接就是「材料的性质」一课：让孩子比较木/石/铁哪个能挖钻石 = needsTool 机制的 curriculum 化包装。

### 1.5 道德与法治（统编版）
- **社区任务线**：帮 NPC 修路（规则意识）、分享食物给饥饿村民（关爱）、垃圾分类方块桶（环保课）、家庭安全检查关卡（用电=红石安全、火=火把/TNT 摆放）。
- **班级共建服务器玩法**（远期多人）：公共产线要轮流值班——规则与合作。

### 1.6 音乐（粤教花城版）
- **音符盒方块**（红石家族新成员）：右键调音高，红石脉冲顺序播放 = 孩子搭「曲子」；教材歌曲简谱直接做关卡谱面（按谱搭 → 播放验证，AI 判音准序列）。
- 已有 BGM 态态机扩展「演奏模式」：孩子用 1-7 数字键现场演奏，连对旋律解锁曲目进自己的「点唱机」。

### 1.7 美术（岭南美版）
- **像素画板**：16×16 方块画布（与纹理图集同规格），画完可「变成真实方块」进自己的物品栏 = 孩子自己给游戏画贴图（textures.js 覆盖机制已有！assets/textures/ 覆盖链）。
- **三原色混色台**：染料方块混色解锁调色盘（色彩课）。
- **建筑作品展**：用已有录像系统拍「我的小屋」讲解视频 = 美术展示与评价课。

## 2. 系统层新增（跨学科共享基础设施）

1. **任务/成就系统 `js/quests.js`**（几乎所有玩法的载体）：课本单元 → 任务链 → 奖励物品/解锁区域。数据驱动（config 纯表），课本内容离线从 PDF 提取整理成 JSON 题库（生字表/单词表/古诗/口算题）。
2. **NPC 系统**（entities.js 扩展）：村民类被动生物 + 对话气泡 + 交易/出题接口；出题引擎可先由规则题库驱动，AI 助手做兜底讲解。
3. **Keypad/答案方块**：红石组新成员，输出信号强度 = 答案数值（天然融入红石减法/比较器玩法，高年级还能升级）。
4. **课本数据管线** `tools/textbook_extract.py`：从 14 本 PDF 抽取生字表、单词表、古诗、口算——一次性入库 `assets/edu/grade3.json`，游戏纯静态加载。
5. **家长报告页**（设置浮层新增）：学习进度、错题本（localStorage），把「玩」翻译成「学」给家长看。

## 3. 分期路线（先好玩后完整）

| 期 | 内容 | 理由 |
|---|---|---|
| **M1 原型（2 个学科验证）** | 数学密码门（keypad+红石）+ 科学水循环小关 + 任务系统最小版 | 全部挂现有系统，改动最小，最快验证「解题欲望」是否成立 |
| **M2** | 题库管线（PDF→JSON）+ NPC 商人（英语）+ 识字矿石（语文）+ 家长报告 | 内容规模化 |
| **M3** | 音符盒、像素画板（音乐美术）、古诗密境、道法任务线 | 偏内容型，依赖前面基建 |
| **M4** | 多人/班级服务器、AI 助手深度陪学（讲解错题、出个性化题） | 远期 |

## 4. 风险与红线

- **Feature Creep（SE-2 最大风险）**：14 本书全铺开 = 每科都浅。坚持 M1 只做 2 学科 3 个玩法，孩子测试通过再扩。
- **「换皮考试」陷阱**：任何玩法若孩子觉得「这是题」，砍掉重设计；题目永远藏在「我要开门/我要交易/我要过关」的意图后面。
- **纯静态红线**：题库走 JSON 静态加载，不引入后端；家长报告存 localStorage。
- **版权**：课本内容只做内部学习用途提取（生字/单词/古诗本身不受版权保护的部分），不大段复制课文文本。
