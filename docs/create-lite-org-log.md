- [G1] 批次冻结：**L1 = 传送带 + 离合器 + 投料器**（每批 ≤3）。叙事：水车→粉碎→带→投料器再投料 + 拉杆一键启停 = 无人值守产线闭环。方案文档 docs/l1-logistics-plan.md（实施代理起草，协调代理定调框架：ID 202..217 新段 + isKineticId 多区间；离合器 engaged 态编码进 ID 照 dustLit 回写、红石边沿触发动力重算；带 carried 模式扩展 items.js；投料器照锯骨架）。
- [G1] 性能基线实测（协调代理，独立 Chrome 19402）：场景 100 轴 + 火把时钟。**方法学裁决**：rAF 端到端帧率在 CDP 自动化环境受窗口遮挡节流不可靠（两次尝试 60s 墙钟分别得 163 帧 / 游戏时间仅走 9.8s，flag 禁节流无效）→ 基线与 G3 性能门**统一用确定性手动泵指标**（四 tick 函数 dt=1/60 驱动 1200 帧的每帧耗时分布 + 全量重算单次耗时）。实测：tick mean 0.45ms / p95 3.1ms / max 4.5ms；红石重算 3.0ms；动力重算 2.1ms。阈值 ×1.2 已写入 plan §6.2 与 L1-P01..P04。
- [G1] 协调代理对起草代理「四处细节完善」的预裁决（G2 评审仍可攻击，终裁在 G2）：
  - ① 投料器捕获格 {T, T+up, D+up} 三格并集：**采纳**——框架句「朝向格正上方」有几何缺口（物品实体无支撑面不会悬停），三格并集是闭环成立的必要修正而非改玩法。
  - ② 带↔带相邻同分量传导：**采纳**——Create「整条带单点驱动」的离散版，逐格贴轴会毁掉布线玩法；R1/R3 重点核「带成为绕过齿轮换向规则的传动缆」是否引入转向矛盾。
  - ③ isCellActiveNow 快照导出 + redstone→kinetic 新增 import：**采纳**——redstone↔piston 双向运行时循环有先例，均无模块顶层调用。
  - ④ 投料器可投物域收窄为普通方块（排除 customMesh 贴面道具/门/工具/材料）：**采纳**——直放贴面道具会产生无支撑红石/半扇门等非法状态。
  - 差异 12「带失去支撑不脱落」：**留 G2 裁决**（R2 攻击面正中）。
