认识三个新组件

手摇动力器

对准后按住右键或 X 供能，松手即停。开面板、移开准星或切换相机后，要重新按下。

手动动力源

大齿轮

大齿轮带小齿轮，变成两倍速；小带大，变成半速。啮合会反转，沿同一根轴串接则等速同向。

速度改变，负载也改变

红石换向器

串进传动轴：无红石信号时直通，有信号时两端反向。可修正两个动力源合流时的旋向冲突。

黄标＝轴正向端

在工作台制作：手摇＝木板×4＋木棍×2＋铁锭×1；大齿轮＝木板×8＋传动轴×1；换向器＝传动轴×1＋红石粉×1＋铁锭×2。实际材料以背包配方为准。

速度与负载，是两项一起观察的量

游戏中，每个机器的基础负载乘上它自己的速度倍率。增加动力源可增加容量，不能把它们的转速直接相加。SU 是游戏的负载预算；这里不把它当作真实世界的扭矩或功率单位。

在游戏里做四个实验

  1. 手摇运输台：在创造或关卡编辑器按 B，选模板后对准地面盖章。把物品丢上带，对准手摇按住右键或 X，比较停与走。普通世界的末端箱子会自动收货；编辑器内只体验运输。
  2. 变速对照台：对准各段动力块读 HUD。大带小与小带大各运行相同时间，比较带上物品走过的距离。齿轮端面沿轴串起来，是否仍然变速？
  3. 升降实验台：站上平台，抬头操作机头底面的拉杆：打开卷绳上升，关闭放绳下降。对比转速与平台跨格速度；在乘客前方设障碍，检查平台停下，撤掉障碍再运行。
  4. 合流纠偏台：双水车经奇数次啮合后旋向冲突，整网停机。打开换向器旁的红石开关，观察机器恢复工作、容量合并；关闭开关再次验证。

手摇只能在普通世界或编辑器操作，闯关模式禁用。要贴着手摇放其他方块，按住 Shift 再右键。

连接、方向与读数

要观察的现象当前组件规则
大小齿轮怎么接同轴端面相接：1 倍同向。平行轴横向相邻：至少一只是大齿轮才啮合。垂直轴相邻、连线沿其中一轴：可啮合。啮合均反向，倍率取决于大小。
方向从哪边看从轴正向端看：X 为东侧，Y 为上侧，Z 为南侧。HUD 正转按右手轴正角速度定义；比较两个轴时先选同一观察端。
换向后带会倒走吗运输始终沿传送带箭头；滑轮仍由红石控制卷/放绳。轴旋向影响传动兼容关系，锯、粉碎轮、投料器在两种旋向都可工作。
电梯怎样上下走垂挂滑轮：充能向上卷、断电向下放。顶举滑轮：充能向下卷、断电向上放。动力中断时平台悬停。
怎样读速度基准转速对应 1 倍速；可使用范围和实际机器速度见准星 HUD。

机关不动时，从这里检查

提示或现象下一步
没有动力检查水车正上方的水，或重新按住手摇；轴应同轴连接，锯/投料器从背面接入；检查离合器是否断开。
应力超载减少机器或降速，也可接入转速与旋向兼容的动力源。升速会增加负载。
转速冲突 / 旋向冲突检查合流处的传动倍率与齿轮反转次数。换向器能纠正旋向；转速不同则要调整大小齿轮连接。
超出转速范围减少连续增速/减速级数。超界会整网停止，系统不会偷偷改成另一档速度。
未找到平台 / 行程端点确认平台在滑轮绳方向、绳路无实心阻挡。到端点会停，撤掉目标格障碍可继续。
乘客前方受阻留出乘客头顶和身体空间，检查侧墙、围栏与世界边界。平台会在移动前停下，避免把乘客塞进障碍。
这些是机关建造与基础观察实验。比较时尽量只改一个条件，并记录输入、输出与现象。正文示例使用本游戏的离散方块和负载规则。
