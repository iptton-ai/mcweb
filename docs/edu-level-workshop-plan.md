## 0. 背景与认知定纲

### 0.1 用户认知（产品总纲性前提）

- 刻意练习 ≠ 苦；苦来自认知。做认为有趣的事只会乐在其中。
- 学习平台替代不了线下刻意练习，**平台只承载引导兴趣**；刻意练习在平台之外。
- 市面「游戏化学习」= 游戏化积分 + 人物互动贴在答题上，本质依然是学知识——没有意思。
- 设想：**彻底游戏化的平台，儿童可以在里面设置关卡，关卡才是真正的知识**。
- 青少年要让学到的知识**马上能用上**（游戏通关或社交炫耀）→ K12 平台的职责=引导兴趣产生主动性。
- 成人是另一类产品（提效助手，练习大部分在平台内），**不与本路线混做**。

### 0.2 设计判据：收费站 vs 承重墙

一句话判据，评审任何 edu 新玩法先过这一遍：

- **收费站**（市面产品病根）：玩到一半弹题、答对放行，题与游戏互为两张皮，题目=打断快乐的时刻。
  变体=积分/奖励挂在答题上（M2 商人+奖励梯队现状，孩子会「为传说掉落而刷题」）。
- **承重墙**（本路线目标）：知识是乐趣的构成材料，拆掉墙游戏就塌。知识既出现在「我要过的关」，
  也出现在「我要造的关」。
- 本作是少数能做承重墙的平台：红石/齿轮/应力/活塞是**真机制真的需要算**
  （齿轮比、信号衰减、应力预算 64 SU 撑不起两台电梯 80 SU），不是贴纸。

### 0.3 现状审计（2026-09-15，M1/M2 已上线）

| 模块 | 审计结论 | 处置 |
|---|---|---|
| M1 答题机（KEYPAD_BASE=224） | 承重墙雏形：知识是钥匙，开门是物理结果，可接红石远控。但孩子只在**答题者位**，题永远是题库出的 | P0 升级出「出题模式」，翻转到作者位 |
| M2 商人三选一 + 奖励梯队 | 收费站模式：积分挂答题。新鲜期内有效，外部奖励逐渐挤出内在兴趣 | **冻结，不再加码**（2026-09-09 已定）。商人保留在世界里填充生态 |
| 家长报告页（⚙️「📚 学习」） | 监控框架 | P2 翻转为「交接卡」（带走清单+下周预告） |
| 总纲 M3 候选（水循环/古诗密境等） | 全部消费侧内容 | 挪进作者框架后再做（本文档取代） |

### 0.4 核心主张：让孩子站到「作者位」

「关卡才是知识」落地为三个作者行为，每个都天然强制掌握：

1. **出题要会**：给自己的地牢设算式锁/单词锁——要设一把能用的锁，必须知道正确答案、
   分得清干扰项哪个是错的。**没法出自己不会的题**（出题=Bloom 最高层「创造」，
   且产出的不是分数而是作品）。
2. **机关要算**：关卡设计图本身就是应用题，而且答案可以玩——红石时钟周期×次数=定时门、
   齿轮比=转速匹配、应力预算=电梯数量上限、活塞推程 12 格=传送带长度。算错机关就不动：
   错误可见/可归因/可恢复（对齐 edu-platform-vision 试错哲学）。
3. **线索要写**：为让**别人**能通关而写英文路标/提示卡/字谜——最高强度的语言使用场景。

关卡=学习作品=炫耀物：炫耀的是「我造的地牢」，不是「我答了多少题」。

## 1. 总路线图

### 1.1 P0–P3 一览

| 期 | 名称 | 一句话 | 量级 |
|---|---|---|---|
| P0 | 关卡工坊最小闭环 | 孩子（或老师）在自家世界造带知识锁的闯关卡，导出关卡卡文件，别人导入玩，通关结算 | 中批次（L2 量级） |
| P1 | 炫耀回路 | 关卡宣传片一键生成 + 成绩海报，把「我造的关」变成班级圈社交货币 | 小批次 |
| P2 | 拉力+回流 | 预告型密室制造「想要但还不会」；家长页翻转为带走清单+下周预告；回流率埋点 | 中批次 |
| P3 | AI 三角色 | 出题协作者 / 苏格拉底提示者 / 单元主题关卡草稿生成；考核锁冻结提示 | 小-中批次 |

### 1.2 认知 → 机制 → 期别映射

| 认知条款 | 机制 | 期 |
|---|---|---|
| 关卡才是知识 | 出题模式（作者侧答题机） | P0 |
| 知识马上能用上（通关） | 关卡框架+知识锁、闯关模式锁破坏=不可绕过 | P0 |
| 知识马上能用上（炫耀） | 宣传片/海报/周五关卡日 | P1 |
| 平台制造需求而非供应练习 | 预告型密室（超纲技能门） | P2 |
| 刻意练习在平台之外 | 带走清单+下周预告，导出纸面练习 | P2 |
| 卡住时引导不代劳 | AI 苏格拉底提示（考核锁可冻结） | P2 文案 / P3 机制化 |
| 作者位（AI 是协作者不是代做） | AI 出题检查/关卡草稿生成，创作权在孩子 | P3 |

### 1.3 产品级成功判据（北极星与代理指标）

- **北极星=回流率**：孩子按带走清单练完后，一周内**主动回来**解锁同知识点的比例。
  明确**不用平台内时长**做指标——时长越长越说明练习被搬进了平台内，方向反了。
- 代理指标（全部 localStorage 本地统计，家长页可见，无后端）：
  周主动开玩次数、作者行为发生率（出题/导出卡的孩子占比）、向 AI 助手要提示次数。
- 验证方式：上线后与 M1/M2 基线组对照上述代理指标；每期做 3~5 个目标年级儿童可用性测试
  （任务示例：「造一个能关住你朋友的关卡」，观察是否需要教、是否说出「这是做题」）。
- **红线（延续总纲 §4）**：孩子若觉得「这是题」，砍掉重设计。

## 2. P0 关卡工坊最小闭环

### 2.1 目标与用户故事

- 作者：小明在自家世界搭了条跑酷走廊，放 3 把算式锁，拿起「出题笔」逐把出题
  （自拟算式或从题库抽），**连过自己的锁两次**完成校验，按 K 导出关卡卡
  `小明的火焰地牢.level.json` 发到班级群。
- 玩家：小红导入关卡卡进入闯关模式，计时开始；答错锁门不开；掉岩浆回检查点；
  踩终点旗结算（用时/死亡/答题明细/星级），成绩存本机可重试刷星。
- 老师：同一工作流——造一张考核关发全班（考核锁=冻结 AI 提示的字段，P0 仅占位）。

### 2.2 范围冻结

**做**：
1. 关卡框架运行时：起点/检查点/终点旗方块、计时 HUD、掉界与死亡回检查点、结算面板与星级、最佳成绩。
2. 闯关模式隔离：禁挖掘、禁放置、禁 E 背包（右键白名单：答题机/门/拉杆按钮/TNT 保留）。
3. 出题模式：出题笔物品 + 作者面板（自拟题/题库抽题、学科标签、双通过校验、选项查重）。
4. 关卡卡 v1：区域快照 RLE + 题目全量拷贝 + 规则字段；导出/导入/本机关卡列表。

**不做**（防 feature creep，逐条后挪）：前扑/翻滚技能、齿轮接触击退、AI 选手、
海报与宣传片（P1）、预告密室与带走清单（P2）、AI 工具（P3）、字谜碑等新锁具（后续批次）、
在线画廊/排行榜/多人（架构红线，永不做开放广场）、老师专用 UI。

### 2.3 关卡框架（运行时）设计

- **旗组方块**（走「新增有状态方块」标准流水线 config→textures→chunk→interaction，
  新 ID 从 229 起按 config.js 编码惯例分配）：起点旗/检查点旗/终点旗三变体。
  普通生存/创造世界里放置无害（无 levelRun 语境踩终点不触发结算）。
- **关卡运行世界**：导入时把卡片区域嵌入**标准尺寸世界**（256×256×128）的固定偏移
  （如中心 x=80..175、y=4 起、z=80..175），四周空气、底部基岩平台——零全局重构，
  generateWorld 跳过直接铺方块。退出即弃（成绩另行持久），不写存档槽、不动 clearBuildQueue 语义。
- **state.levelRun**：{cardHash, spawn, respawn, activatedCheckpoints, timerStart, deaths,
  answers:{锁坐标:{tries,solved}}, rules}。uiModal 不加新态（playing 照旧），
  首屏新增「🗺 关卡」入口 → 关卡列表页（导入文件/点卡开玩/删除）。
- **检查点**：踩检查点旗即设 respawn=该旗（重复踩刷新）；死亡（含掉界 y<0/出区域）走
  playerLife 既有死亡流程但重生点改 levelRun.respawn，背包保留照旧，计时**不**停，
  deaths+1。rules.timeLimit 可选，超时=失败面板（重试/退出）。
- **结算**：踩终点旗 → 结算浮层（新 uiModal 态 `result`，只读）：
  用时/死亡次数/每把锁的尝试与对错明细/星级。星级默认规则：3 星=零死亡且全部锁一次过、
  2 星=通关且零死亡或全部锁最终答对、1 星=通关。最佳成绩存 localStorage（见 §6.2）。
- **模式隔离（承重墙铁律的实现层）**：闯关模式左键挖掘无效、右键放置无效、E 背包禁入
  （interaction.js / input.js 加 levelRun guard）。知识锁因此**不可拆不可绕**。
  潜行/疾跑/游泳照常；TNT 右键点燃保留（关卡陷阱是玩法）。

### 2.4 出题模式（作者侧）设计

- **出题笔**（新物品，非方块）：创造物品栏发放 + 工坊快捷授予；手持出题笔右键答题机 →
  打开作者面板（不持笔右键=玩家答题，现有行为不变，语义清晰：拿起笔=我要出题）。
- **作者面板**（复用 M1 答题 UI 骨架 + eduKeypad 引擎）：
  - 通用题结构=题干 + 3~4 选项 + 正确索引（或数学数字答案 0..9999，契约 §2 不变）；
    学科只是标签（徽标沿用），英语自拟=中文释义+单词选项，语文自拟=字词+选项。
  - 数学自拟算式可由系统算答案，也可自填；「从题库抽」按学科+单元过滤（banks.json 契约照用）。
  - **考核锁开关**：写入 rules.lockAIHelp=false（P3 起助手尊重此字段）。
  - **发布校验（导出门槛）**：① 作者必须连过自己这把锁**两次**（防手滑、防不会）；
    ② 选项查重（不重复、与答案不同）；③ 数学答案范围校验；④ 数字题答案唯一性。
- **题目存储**：自拟题与题库抽题**全量拷贝**进关卡卡（自包含，不随题库版本漂移——
  题库更新不应篡改老关卡作者意图），带 subject/unit 元数据供 P2 交接卡归因。
- P0 锁具只有答题机一种（复用 M1 全部题型：数字输入+三~四选一，天然全学科可用）；
  商人/识字矿石不改（可放进关卡但非锁具）。

### 2.5 关卡卡格式与导入导出

- **格式 `mcweb.level.v1`**：
  `{format, name, author(本地填写的昵称，不采集任何真实信息), created, version,
  region:{x0,y0,z0,w,h,d,blocks(RLE)}, questions:[全量题+锁坐标], rules:{timeLimit?, starRules?, lockAIHelp},
  flags:{start, checkpoints[], goal}}`
- **尺寸上限 96×64×96**（够跑酷+地牢；RLE ~0.11 B/格 ≈ 数十 KB，文件分享无压力）；
  RLE 编解码直接复用 saveGame.js 的 rleEncode/rleDecode（exportSlotJson 同模式）。
- **区域自动检测**：按 K 打开导出面板 → 以全部旗子+全部非空气方块的联合包围盒 +2 格边距
  自动计算区域（孩子不用框选）；超上限给缩围提示。
- **导出校验**：起终点旗存在、全部锁 verified（双通过）、题目合法性（§2.4 ④）；
  可选加分项（放 P0 或 P3 均可）：从起点出发的**静态可达性 BFS**（把门/答题机相邻门视为可通行）
  提前拦截「不可通关废卡」。
- **导入**：文件选择 → 格式与方块 ID 合法性校验 → 进本机关卡列表。文件级分享走微信群
  （班级圈层，无后端，见 §6.1）。
- **存储位置**：卡片与缩略图（P1）存 **IndexedDB**（原生无依赖不破纯静态；localStorage 配额
  已被 6 存档槽逼近 5MB，塞不下几十 KB×N 张卡片）；成绩与元数据仍走 localStorage。

### 2.6 决策点与推荐裁决（G2 对抗评审重点）

| # | 决策点 | 推荐 | 理由 |
|---|---|---|---|
| D1 | 起终点=新方块 vs 坐标区域 | **方块** | 放旗子=6 岁都会；快照天然自带；AI 造关卡（P3）用同一接口。代价是走一遍新方块流水线（已趟熟） |
| D2 | 关卡入口=首屏独立区 vs 存档槽 tab | **首屏独立区**（槽位列表上方一行「🗺 关卡」） | 槽=世界、关卡=另一类资产，语义不混；切世界编排（main.js）零改动 |
| D3 | 闯关模式禁破坏/放置/E | **全禁** | 机关完整性+知识锁不可绕（承重墙铁律）；跑酷玩法不需要挖放 |
| D4 | 卡片题目=全量拷贝 vs 题库引用 | **全量拷贝** | 卡片自包含，不随题库版本漂移 |
| D5 | 卡片存储=localStorage vs IndexedDB | **IndexedDB**（成绩/元数据留 localStorage） | 配额账算不过来（§6.2） |
| D6 | 区域上限 | 96×64×96 | 量级够用且文件/内存可控 |
| D7 | 出题笔获取方式 | 创造栏+工坊授予（生存合成后续再说） | P0 少一条合成链路 |

### 2.7 E2E 验收候选清单（冻结前定稿，建议 `tests/e2e/run_workshop.py`）

- W01 模式隔离：闯关模式挖掘/放置/E 均被拒；普通存档槽玩法回归不受影响。
- W02 检查点：死亡→回最近激活旗，计时连续，deaths+1；重复踩旗刷新。
- W03 终点结算：用时/死亡/答题明细/星级计算正确；rules.timeLimit 超时走失败面板。
- W04 锁具联动：关卡内答题机答对→翻转供能→红石开门（连带跑 run_regression 红石相关用例）。
- W05 出题校验：未双通过不能导出；选项重复被拒；数字题范围校验。
- W06 卡片回环：导出→删除→导入→区域方块与题目逐字段一致。
- W07 嵌入展开：导入后区域落在标准世界固定偏移，四周空气/底部基岩正确，玩家出生在起点旗。
- W08 性能门：导入构建+首帧渲染耗时阈值（按 P01 门风格实测定）。
- W09 成绩持久：星级/最佳成绩写 localStorage，重开关卡列表仍在。

## 3. P1 炫耀回路

### 3.1 目标与用户故事

- 小明把「小明的火焰地牢」宣传片（mp4）发到班级群；小红通关后生成成绩海报（PNG）回帖。
- 班级圈层形态=**周五关卡日**：老师收全班的关卡卡，课上互相攻城，评「最难/最好玩」。
  排行榜排的是**关卡**（被通关次数/通关率/好评），不是答题分数。P1 无后端，
  「排行」=老师线下的海报墙；本机卡片显示被玩次数与最佳成绩。

### 3.2 范围冻结

做：关卡宣传片（玩家实录一键开录）；成绩海报 PNG（关卡缩略+成绩+称号）；关卡列表缩略图缓存。
不做：自动巡航宣传片、在线画廊/排行榜、点赞评论（无后端永不做开放广场）。

### 3.3 关卡宣传片

- 入口：关卡列表与结算面板「🎥 拍宣传片」→ 一键开录 → 通关/退出自动停止保存。
  编码复用 recording.js（H.264+AAC mp4 已锁，自动下载）。**不动 recOwner 所有权模型**
  （run_rec.py 3 用例必须回归：用户录像不被施工收尾停止的语义原样适用于关卡）。
- 自动巡航版（build 相机套用 cameraRig 的八角包住取景）后挪：玩家实录更真实、含答题过程。

### 3.4 成绩海报与缩略图

- 结算面板「📸 生成海报」：canvas 渲染关卡缩略（斜视角截图或俯视渲染）+ 关卡名/作者/
  星级/用时/称号（如「火焰地牢首杀」）→ canvas.toDataURL 下载 PNG。
- 缩略图：导入卡片时离屏渲染一帧小图存 IndexedDB（随卡片），列表展示；失败降级为程序化占位图。

### 3.5 决策点 / E2E / 量级

- 决策点：海报渲染用主 canvas 截帧（简单）vs 专用斜视角离屏渲染（好看）——推荐先截帧，
  效果不满意再升级；缩略图尺寸 256×256 JPEG 压缩（控制 IndexedDB 体积）。
- E2E：宣传片与 recOwner 共存（run_rec 回归）；海报/缩略图文件非空；缓存失败降级不报错。
- 量级：小批次（一个会话可完成）。

## 4. P2 拉力与回流

### 4.1 目标与用户故事

- 小明在自家世界里发现一扇「星辉门」，右键：「需要技能：三位数除法（三下·第五单元）——
  练成后回来」。这是他还没学的单元。他答错了，门说：「这个还没学哦——想要提前解锁吗？
  找 🤖 要个提示，或这周练完回来。」错题进了他的「带走清单」。周末他在纸面上练了三位数除法，
  周一回来把门开了——**这次回流被记录为一次成功指标**。
- 家长在 ⚙️「📚 学习」页看到的不再是监控报表，而是「本周交接卡」：游戏里遇到但没解开的题
  （按学科分组、附题干与对应课本单元）+「下周预告」+ 回流趋势。

### 4.2 范围冻结

做：预告型密室（星辉门方块+超纲抽题）；学习进度设置（学期+最近单元）；
错题登记（仅关卡/预告场景，上限 50 条滚动）；交接卡页翻转与打印导出；回流/主动开玩埋点。
不做：AI 提示机制化（P3，P2 只做文案引导跳转助手面板）；定时真解锁（预告=文案，
随时可挑战，诚实不搞假倒计时）；任何刷题/间隔重复功能（平台保持薄）。

### 4.3 预告型密室（「想要但还不会」）

- **星辉门**（新方块，与答题机同族的锁具变体）：右键展示超纲知识点面板并出题——
  答对=开门（记录「提前解锁」，强激励）；答错=温和文案 + 入错题本 + 引导找助手要提示。
- 「超纲」判定：设置页「📚 学习」新增**当前学习进度**选择器（学期+最近单元，默认三上第 1 单元；
  不依赖任何账号）。「还没学/还没解锁」= 题库单元序列中当前进度之后的单元，
  按 格哈希确定性抽题（同格同题，沿用 M1 契约）。
- 星辉门同样进关卡卡（又一种作者可用的锁：老师可造「预告关」）。

### 4.4 带走清单与下周预告（家长页翻转）

- **错题登记**：现有 mcweb.edu.v1 只有计数（solved/wrong/streak/p.subjects），无逐题记录。
  新增错题本结构（仅记关卡/预告场景）：题干+学科+单元+时间+来源（关卡名/星辉门），
  上限 50 条滚动淘汰。
- **交接卡**（「📚 学习」页重构）：错题按学科分组展示，答案折叠（家长可控展开）；
  顶部「本周带走」汇总 + 「下周预告」（按单元序列生成文案：下周将遇到的知识点）；
  「🖨 打印」= 打印样式 window.print（决策点：print CSS vs PNG，推荐 print CSS，清单是文字为主）。
- 指标埋点：回流事件（星辉门错题→七天内同知识点开门=1 次回流）、周主动开玩次数、
  求助提示次数（P3 前记「打开助手」）。全部 localStorage 聚合，家长页显示趋势。

### 4.5 决策点 / E2E / 量级

- 决策点：错题本容量（50 条）；回流窗口（7 天）；进度选择器粒度（单元级足够）。
- E2E：星辉门按进度选后续单元且同格同题；答错入错题本并滚动淘汰；交接卡聚合与折叠正确；
  打印导出非空；回流事件判定（模拟错题→改进度→开门→计数）。
- 量级：中批次。

## 5. P3 AI 三角色

### 5.1 出题协作者

- 助手新工具 `check_level`：读当前区域/关卡卡，校验锁具（选项重复/答案合法/难度标注/
  超纲提示/（若做）可达性 BFS 报告）。孩子在工坊里说「帮我检查我的锁」→ 工具报告
  （对话可见，逐条可点跳转）。依托 tools.js + 助手文件 API 既有骨架。

### 5.2 苏格拉底提示者

- assistant/docs.js 注入 levelRun 上下文（正在挑战的锁的题干+课本单元+考核锁标记），
  系统提示词约束梯度提示：先反问（「你觉得这是求总数还是分组？」）→ 方法提示 →
  「还要更直接吗？」；**绝不直接给答案**。
- 考核锁（rules.lockAIHelp=false）：助手在该锁上拒答提示（「这扇门要靠你自己」）。
  P0 的字段在此生效。

### 5.3 单元主题关卡草稿生成

- 助手新工具 `gen_level_draft`（参数=单元/知识点/风格模板）：从题库抽 N 题装锁 +
  build_script 建造（跑酷/地牢/寻宝三模板）→ 产出关卡卡文件，孩子导入后**可编辑**。
  AI 造的是草稿，**作者位仍在孩子**（与 edu-platform-vision 的「计划卡学生填」同构）。

### 5.4 无头试玩验证（远期可选）

- 用 CDP/E2E 基建（tests/e2e/lib.py）机器人导入卡片→自动答题（卡片自带答案）→
  路径走查，分享前验证可通关。**静态可达性 BFS 若已进 P0 导出校验，此项降为远期**。

### 5.5 安全与边界

- 助手对话与记录全本地（现状不变）；考核锁冻结提示；AI 不代答题（系统提示词红线）；
  生成草稿使用的建造走 buildQueue 渐进施工（既有性能约束）。

### 5.6 E2E / 量级

- E2E：check_level 报告正确性（构造坏锁）；考核锁提示拒答；gen 草稿可导入可编辑。
- 量级：小-中批次。

## 6. 横切关切

### 6.1 架构红线

- **纯静态**：无后端、无构建工具、无第三方依赖（IndexedDB 原生可用不违例）。
  分享一律文件级 + 班级/家庭圈层（微信群），不做开放画廊/在线服务——
  未成年 UGC 开放广场的内容审核背不动，圈层化后无需审核基建。
  昵称=本地填写不采集真实信息；题干自拟文本由监护圈层自控。
- **IP**：跑酷闯关玩法机制不受著作权保护；命名避开「蛋仔/派对/马里奥制造」等商标，
  「关卡工坊/关卡卡」为通用词（本作自身的改名议题另案，见 minecraft-ip-risk 记忆）。
- **手感隔离**：闯关模式的一切交互限制都是 levelRun guard，不污染生存/建造玩法
  （playerPhysics 零改动；W01 回归守住）。

### 6.2 存储预算

| 数据 | 位置 | 量级 |
|---|---|---|
| 存档槽 ×6 | localStorage | ~880KB×6（现状，已逼近 5MB——卡片不能进 localStorage 的原因） |
| 关卡卡 + 缩略图 | IndexedDB | ~40KB+~30KB × N 张，N 上限提示（建议 50） |
| 成绩/元数据/错题本/埋点 | localStorage（mcweb.levels.v1 / mcweb.edu.v1 扩展） | <100KB |

### 6.3 风险清单

- Feature creep（总纲 §4 同款风险）：P0 严守 §2.2 不做清单，儿童测试通过再扩。
- 换皮感知：每期儿童可用性测试是发布门槛。
- 配额与降级：IndexedDB 不可用/超限 → 关卡卡退化为「会话内」（导入即玩、刷新即失）并明确提示。
- 题库版本漂移：已由 D4（全量拷贝）消解；自拟题不回写公共题库。
- 存档安全：关卡运行世界为临时构建，绝不能写回存档槽（W01/W07 覆盖）。

### 6.4 分学段落点（本路线完成后的延伸方向，不排期）

- 小学低段：模板化创作（地牢骨架+换锁换线索，低门槛高产出）。
- 小学高段/初中：自由创作 + Create 式约束挑战赛（限应力预算/零件数=优化题），社交以视频为主。
- 总纲 M3 候选内容（水循环/古诗密境/音符盒/像素画板）逐一改造成「孩子可设置的锁/线索/机关」后回归。
