# 物理组件补全：E / W / A 实施契约

2026-10-22，承接物理首批。用户已要求继续实现剩余全部组件，按依赖分成小批依次落地，不再停留于规划。

## 范围与兼容

E0–E6：有界实验台、标准物体和砝码、坡度与三档摩擦、可移支点杠杆、手动储能弹簧、定/动/组合教学滑轮、测速计时测力、接轴机械风扇。W1–W3：四份容量局部槽、闸阀、机械泵、浮块配重。A1–A3：三格宽直线平台、固定竖轴风车、独立实验落块和运动 TNT。旧水、沙砾、TNT 不改规则。

本批明确修订 create-lite-org-plan §0.2.1 对本批的适用范围：世界仍用 Uint8 与原 RLE；允许可选 `physics:{v:1,devices:{坐标:{id,config}}}` 配置，嵌入普通档与快照共用的 home capture，旧档缺字段=空。关卡卡增加可选 physics，局部坐标且先校验后嵌入。配置只含有限白名单标量，≤512装置（其中水槽≤256），禁止未知字段/NaN/出界/与地形不匹配；所有导入与快照都验证。运动实验读档回初始姿态，水量存方块ID不复位；移动平台保存实际偏移，运动TNT保存剩余引信。虚拟标准物体不兑换背包，不被拾取。

## 计算与交互

固定1/120秒实验步，单帧最多0.1秒，不追离线；水路0.1秒一轮、≤256格，泵每次事务搬一份，闭闸不删除水。槽可同层均衡或流向相邻低一格槽，槽外密闭。桶只做4份整桶交换，背包事务成功后改水；复位只复位虚拟浮块。

坡台 a=g(sinθ−μcosθ)，坡底连续转水平、静摩擦停稳；物体限制在台内，尺度用游戏单位。杠杆五槽、支点可移、Σmgr决定角度，有限角度仅载标准砝码。弹簧压缩档0..3，手动做功，释放清储能，v=√(k*x²/m)×损耗，碰低顶停止。教学滑轮F=mg/n、绳程=n×提升程，手拉输入后移动物体。读数/动画使用同一状态。

装置右键/X打开统一physics模态；开始按钮关面板继续观察，E/Esc/Q收起。Shift绕过交互放置。作者可配置allowRun；关卡只允许该装置开始/复位，不许改参数、桶、点TNT或开自由建造通道。红石自动激活实验、阀/平台读取同一供能缓存。

宽平台整体检查全部目的格及乘客扫掠，实体去重一次移动，低顶/墙/世界边界/前方人阻挡时全体悬停；不删除安全检查。落块被人挡住停落、不埋人；实际格移动后保存位置，速度读档归零。组件不能被活塞推移/机器吞料，以免配置脱离位置。

## G2 修订与公开验收API

R1/R2/R3/R4/R5独立意见已裁决：配置白名单明确包含平台`offset`（0..length）、运动TNT`armed`与`fuse`（0..2.5）；其余动态值不保存。平台复用真实PLATFORM_BASE，驱动器上方y+1、沿dir移动、横向width=1/3，加载核对实际足迹。卡片保存当前offset作为该卡起点，拒绝导出已点燃运动TNT；重试从卡片起点开始。带physics的卡hash纳入规范排序配置，旧卡hash保持。槽与装置合计最多512、其中流体最多256、每步活动实验最多32。虚拟实验体/杠杆/浮块模型全部留在所属单格内，不载玩家。

闸占一格，两端相隔2格槽通过闸连接；open手动状态与control红石模式明确互斥。红石自动开实验可由作者电路驱动，手动开始/复位必须allowRun。风车监视以其中心x/z±2、y+1..3体积的所有solid变化，只有开阔电平改变才重算。落块只与普通WATER交换，实验槽挡路；移动时原子迁移配置。平台旧格站顶者才载运，目的格旁观者阻挡，所有乘客共享所有权去重。

公开API：`initPhysicsLab()`重建索引/清瞬态；`tickPhysicsLab(dt)`固定步进；`configurePhysicsAt(x,y,z,patch)`返回`{ok:true}`或`{error}`；`physicsActionAt(x,y,z,action)`同返回型（start/reset/compress/pull/toggle/ignite）；`physicsInfoAt(x,y,z)`返回null或当前配置、running/elapsed/distance/velocity/height/angle/torque/force/ropeDistance/water/blocked/status等读数。配置、动作权限在API入口执行。数据API `capturePhysicsState(region?)`、`validatePhysicsState(raw,blocks,dims?)`、`restorePhysicsState(raw,offset?)`供普通档/快照/关卡共同消费。缺字段兼容，非法数据拒绝；验证先于覆盖世界。


## G3 独立差异复审回流

三名新上下文审查者分别只看完整diff、追踪边界分支、按验收契约实跑。18项可达遗漏按patch修复（含最后风车定向复核两项），未改变本批目标或公开玩法边界；一项“失支撑挂件未重算”原本已由popUnsupportedRedstone末尾重算处理，查callee后排除。新增回归覆盖最后源移除/边界信号别名、跨层风路、逆风/侧风、停机带、实际测速交点、换湿槽返还、风力缓存、带侧接口绕过、落块遮挡电路、水车顶水移走与截断平台导出。

明确实现细节：水路/泵/桶的内部换量显式传`setBlockSafe(...,{physicsWaterTransfer:true})`；普通覆盖（含换另一只槽）按容器替换返原湿槽。斜坡试验体只沿东西轨道，风力取该轴投影；实际掉落仍支持四向风。测速对每个真实交点插值侧向/高度，不能仅检查帧终点。移动方块只在邻近红石存在时刷新线路遮挡，沿区块边界同时重建相邻区块。配置hash先补默认字段并统一布尔表示；导出区域截断当前运动平台时明确要求调整旗标。

最后环境复核补充：实心格直接覆盖成风车也强制环境版本变化；床双格清理的原始数组写入向环境通知被清半格。旧世界快路只跳过无物理格且无风车的新增钩子，不跳过配置、配方、支撑或载客校验。最终验收见 physics-rest-verification.md。
