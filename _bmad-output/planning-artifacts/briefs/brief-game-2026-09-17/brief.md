# 产品简报：「我的世界-网页复刻版」（mcweb）教育体素沙盒平台

## 执行摘要

mcweb 是一个已上线运营（2026-09-01 起托管于 https://apps.yltech.store/mcweb/ ）的**纯前端体素沙盒教育游戏平台**，面向三年级小学生：原生 JavaScript + Three.js，零构建、零依赖、无后端、无账号，浏览器打开即玩。孩子在一个高完成度的《我的世界》复刻沙盒里建造与闯关——红石电路、活塞机关、Create 风格动力产线、电梯与录像系统都是真机制——而课内知识是这个世界里的**钥匙与建材**：答题机锁门（题库取自三年级课本，数学 405 题+科学/道法/语文共 597 题校验零违规，另有英语词表与 258 字识字表）、星辉门预告「还没学」的超纲知识、识字矿石挖出生字、英语商人只说英语。

产品的核心主张是「**关卡才是知识**」：孩子不只答题，更站上**作者位**——在关卡编辑器里摆旗组与知识锁、用出题笔给自己造的关卡出题（必须连过自己两次才能发布）、导出关卡卡文件发到班级微信群，同学导入后进入**全封锁的闯关模式**互相攻城。闯关中挖掘/放置/背包/飞行全部被禁，知识锁**物理上不可绕过**。

平台刻意保持「薄」：不做刷题、不做在线社区、不做时长指标。北极星指标是**回流率**——孩子按带走清单在平台外练完后，一周内主动回来解锁同一个知识点的比例。AI 助手（游戏内建造 + 苏格拉底式提示 + 关卡体检）全程只引导、不代答。

## 问题

- **孩子侧**：市面「游戏化学习」的通病是「收费站」——玩到一半弹题、答对放行，题与游戏互为两张皮。新鲜期内有效，之后答题=打断快乐的时刻，外部奖励（积分/掉落）反而挤出内在兴趣。
- **家长侧**：孩子玩沙盒游戏，家长看不见「玩」翻译成了什么「学」；监控式报表引发对抗而非合作，也带不走任何可以线下巩固的东西。
- **教师侧**：缺少一种能布置、能分享、能互相游玩的数字化「作业」形态；面向未成年人的开放 UGC 社区有审核与安全负担，学校与机构不敢碰。
- **认知前提**（产品定纲）：刻意练习≠苦，做有趣的事只会乐在其中；学习平台替代不了线下刻意练习，**平台只承载引导兴趣**；K12 与成人是两类产品，绝不混做。

## 解决方案

三条互相咬合的回路，全部已落地：

1. **玩中学（消费者）**：知识是承重墙不是收费站——开门要算式、交易要英语、挖矿认识字；机关本身也是应用题（齿轮比、红石信号衰减、应力预算 64 SU 撑不起两台电梯 80 SU），算错机关就不动，错误可见、可归因、可恢复。
2. **闯关与炫耀（社交货币）**：14 张内置官方关卡渐进覆盖五学科与红石机关；孩子通关得星级、拍宣传片、生成成绩海报；「周五关卡日」里老师收全班关卡卡、课上互相攻城，排行榜排的是**关卡**不是答题分。
3. **创作与回流（作者位）**：关卡编辑器 + 预设组件库 + 模板库把建关门槛降到儿童可操作；出题=布鲁姆最高层「创造」，且**出不了自己不会的题**。星辉门出超纲题制造「想要但还不会」，答错进错题本；家长页不是监控报表而是**交接卡**（错题按学科分组 + 下周预告 + 🖨 打印），纸面练完回来开门=一次被记录的回流。

双受众各取所需：孩子得到一个值得炫耀的作品与圈子；家长得到可打印的交接清单；教师得到考核锁（冻结 AI 提示）与零审核负担的圈层分发。

## 差异化（诚实版）

- **知识锁不可绕**：闯关模式全封锁（禁挖掘/放置/背包/换模式/飞行/中键/手开门，TNT 炸不毁锁与旗），有 E2E 用例逐项锁死（W01/W11）。这是「承重墙」与「收费站」的分界线，也是与所有弹题类产品的本质区别。
- **孩子是作者**：答案校验靠「连过自己两次」，AI 只出草稿、创作权在孩子；炫耀物是「我造的地牢」而非答题分数。
- **AI 只引导不代答**：苏格拉底梯度提示（先反问→方法→再问），考核锁场景直接拒答；出题协作者与无头验证是工具，不是枪手。
- **真机制平台**：红石/活塞/动力组是少数能让「知识真的承重」的沙盒系统，机关设计图本身就是可玩的应用题。
- **零后端纯静态**：分享走文件 + 班级微信群圈层，无 UGC 广场=无审核基建=未成年人安全合规成本低；昵称本地填写、零数据采集，隐私红线天然成立。
- **不装作的护城河**：本作没有网络效应护城河（刻意不做开放社区），真正的护城河是**内容管线与执行速度**——教材 PDF→题库 JSON→确定性关卡生成器→E2E 全量校验（64 用例锁物理设计、597 题零违规）的自动化生产线，以及一个已经跑通 P0–P3 全程的交付节奏。另：「我的世界」命名存在未决的商标风险（见开放问题）。

## 服务对象

- **主用户：三年级小学生（8~9 岁）**。他们在班级群里互相发关卡卡、攻城、刷星；成功样态=「这是我造的火焰地牢，你敢来闯吗」，而不是「我今天刷了 50 道题」。
- **次用户：家长**。通过 ⚙️「📚 学习」交接卡看懂孩子遇到了哪些没解开的题、下周会学什么，可打印带走；成功样态=拿着打印页陪练 20 分钟，而不是盯着时长报表。
- **次用户：教师/机构**。用考核锁布置「要靠你自己」的课堂关，收卡片办关卡日；成功样态=关卡卡成为一门可布置、可互评的作业形态。
- **明确排除**：成人学习市场（那是另一类产品：提效助手、练习在平台内）。

## 成功判据

- **北极星=回流率**：星辉门错题 → 孩子在平台外练习 → 7 天内回平台解锁同一知识点的比例。**明确不用平台内时长做指标**——时长越长越说明练习被搬进了平台，方向反了。
- **代理指标**（全部 localStorage 本地统计、家长页可见、无后端）：周主动开玩次数、作者行为发生率（出题/导出关卡卡的孩子占比）、向 AI 求助提示的次数；上线后与 M1/M2 基线对照。
- **质量红线**：每期做 3~5 名目标年级儿童可用性测试；测试中孩子若说出「这是题」，该玩法砍掉重设计——这是发布门槛，不是参考意见。
- **可观测性缺口（诚实声明）**：所有指标只存在端内 localStorage，无汇总遥测（架构红线使然）。当前回流率只能靠家长页与线下渠道回收，产品级验证尚未闭环——见开放问题。

## 范围

**已上线（已验证的当下，2026-09-16 止）**：
- 沙盒本体：创造/生存双模式、合成-挖矿-冶炼生存成长线、昼夜/刷怪/饥饿/氧气/摔落、红石组、活塞与粘液块（含载人）、Create 风格动力组与物流组（水车/轴/齿轮/粉碎轮/锯/传送带/投料器/离合器）、滑轮电梯族、录像与拍摄系统、动态 BGM。
- 教育内容锁：答题机（多学科题库，同格同题哈希）、英语商人、识字矿石+图鉴、星辉门（超纲预告+错题本）、奖励梯队（M2 遗产，已冻结不再加码）、家长交接卡。
- 关卡生态：关卡工坊 P0–P3 全量落地（出题笔双通过、mcweb.level.v1 卡片、闯关模式全封锁、星级与最佳成绩、检查点、宣传片与海报）、14 张官方关卡（确定性生成器）、关卡编辑器 + 组件库 + 模板库。
- AI 助手：自然语言建造、源码读写与热重载、关卡体检/草稿生成/苏格拉底提示三角色。

**明确不做（边界即承诺）**：多人联机、在线画廊/排行榜/评论（永不做开放 UGC 广场）、刷题与间隔重复、账号体系与后端、商业化激励、成人提效产品。

**下一步方向（已定纲、按优先序）**：① 总纲 M3 候选内容（水循环/古诗密境/音符盒/像素画板）逐一改造成「孩子可设置的锁/线索/机关」回归作者框架；② 分学段延伸：小学低段模板化创作、小学高段/初中自由创作+Create 式约束挑战赛（限应力预算/零件数=优化题）；③ 题库与官方关卡按学段/教材版本规模化；④ 解决命名商标议题与指标可观测性（见下）。

## 愿景

如果成功，2~3 年后 mcweb 是一个由孩子的作品自转的「**关卡才是知识**」兴趣平台：每个学期，孩子用课内知识造出越来越复杂的关卡，在班级圈层里交换、攻城、炫耀；关卡卡就是学习成果档案，家长交接卡和打印清单把「想要但还不会」的部分安静地导流到平台外；AI 全程陪学但从不代答。分学段自然延展——低段孩子套模板换锁换线索，高段孩子在应力预算与零件数的约束下做优化挑战。平台始终很薄：承载兴趣、制造「想要」，把刻意练习诚实地留在线下。

## 假设与开放问题

本次为无交互后台环境的回溯性文档化，以下不确定处取自事实源并显式登记：

1. **回流率不可远程验证**：北极星指标的埋点只写端内 localStorage，无汇总通道；「回流率作为北极星」目前是设计承诺而非被数据验证的事实。是否引入最小化、合规的匿名汇总（如家长页一键导出统计）待议——当前红线禁止后端。
2. **商标与命名风险未决**：「我的世界-网页复刻版」命名涉及 Minecraft 商标风险（内部记忆 minecraft-ip-risk 已立案「改名议题另案」），简报按现名书写，改名将影响品牌与传播资产。
3. **分发与采用度未证实**：班级微信群/yltech.store 渠道的实际渗透率、教师采用度、儿童留存均无文档化运营数据——【假设】目标用户主要经 yltech.store 主站与班级群文件分享触达。
4. **M2 遗留张力**：奖励梯队（连对掉传说装备）属被定纲否定的「收费站」模式，已冻结但仍在代码与玩家习惯中；是否退役或改造成承重墙形态，未裁决。
5. **内容合规边界**：课本内容提取仅取不受版权保护的部分（生字/单词/古诗/口算），该边界的法务确认状态未记录。
6. **性能与配额债务**：红石/动力全图重算随世界规模线性放大、6 档存档已逼近 localStorage 5MB 配额——扩内容前需先还「元件索引+差分存档」两笔技术债（AGENTS.md 已列为债务项）。
7. **AI 助手的低龄可用性**：助手依赖用户自配 OpenAI 兼容 API Key，8~9 岁儿童独立配置不现实——【假设】AI 角色的实际使用者是家长/教师代配置后的家庭设备。
