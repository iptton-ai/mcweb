# 附录：现状盘点、机制映射与约束明细

## A1. 认知定纲 → 机制 → 回路映射（产品逻辑链）

| 认知条款（2026-09-09/09-15 定纲） | 落地机制 | 回路 |
|---|---|---|
| 关卡才是知识 | 出题笔 + 作者面板（自拟/题库抽题、双通过校验） | 创作 |
| 知识马上能用上（通关） | 知识锁（答题机/星辉门）+ 闯关模式全封锁 | 闯关 |
| 知识马上能用上（炫耀） | 宣传片 mp4 + 成绩海报 PNG + 周五关卡日 | 闯关/社交 |
| 平台制造需求而非供应练习 | 星辉门出「还没学」单元的超纲题（同格同题哈希） | 玩中学/拉力 |
| 刻意练习在平台之外 | 交接卡（错题按学科分组 + 下周预告 + 🖨 打印） | 回流 |
| 卡住时引导不代劳 | AI 苏格拉底梯度提示；考核锁场景拒答 | 全部 |
| 作者位（AI 是协作者） | check_level 体检 / gen_level_draft 草稿 / 创作权在孩子 | 创作 |

**收费站 vs 承重墙判据**（评审任何新 edu 玩法的第一道闸）：玩到一半弹题、答对放行、题与游戏两张皮 = 收费站，砍掉或改造；知识是乐趣的构成材料、拆掉游戏就塌 = 承重墙，通过。

## A4. 架构红线与技术约束（PRD/架构必须继承）

1. **纯静态**：无后端、无构建工具、无第三方运行时依赖；分享一律文件级+圈层（微信群）；永不做开放画廊/在线服务（未成年 UGC 审核背不动）。
2. **零数据采集**：昵称本地填写、进度在 localStorage/IndexedDB；无账号体系。
3. **手感隔离**：闯关/编辑的一切限制都是模式 guard，不污染生存/建造玩法（playerPhysics 零改动，回归用例锁死）。
4. **存储预算**：存档 ~880KB×6 槽逼近 localStorage 5MB；关卡卡 ~40KB+缩略图 ~30KB×N（建议 N≤50）入 IndexedDB，不可用时降级会话内并明确提示。
5. **性能债务**：红石/动力全图线性重算随世界规模放大；世界再扩容前须改「种子+玩家改动差分」存档。
6. **IP 与命名**：玩法机制不受著作权保护；命名避开「蛋仔/派对」等商标；「我的世界」改名议题另案未决。
