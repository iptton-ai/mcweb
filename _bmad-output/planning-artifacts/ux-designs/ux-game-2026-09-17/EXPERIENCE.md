# mcweb — EXPERIENCE.md（体验规范 · 回溯性沉淀）

> 本文描述 mcweb「怎么运转」。视觉规格见 `DESIGN.md`；两份脊线文档冲突时以脊线为准，任何旧实现/截图让位。
> **标注约定**：未标注 = 已实现现状；**【改进建议】** = 对齐 PRD E8~E11 的方向，未排期、不构成承诺。

## Foundation

- **形态（form-factor）**：桌面浏览器单页面 WebGL 游戏。全屏 Three.js 画布 + HTML DOM HUD/浮层叠加；鼠标 + 键盘是唯一输入（指针锁为前提）。**移动端/触屏明示不支持**（PRD NFR-9；触屏适配不在 E8~E11 任何方向内，见「已知痛点」声明）。
- **UI 系统**：无框架、无组件库——原生 ES Modules + 直接 DOM 操作。没有可继承的设计系统；视觉 token 自立于 `DESIGN.md`，行为规范即本文。**浮层显隐与指针锁的唯一管理者是 `js/uiModal.js` 状态机**：除它之外任何模块不得调用 `requestPointerLock/exitPointerLock`（架构铁律，新增浮层一律接入状态机或其登记的非暂停浮层标志）。
- **双世界结构**：游戏内一切 UI 分三种挂载方式——① 互斥游戏状态模态（title/pause/inventory/settings/dead/result）；② 非暂停浮层（拍摄面板/导出面板/组件库/作者面板：指针让位、游戏照跑）；③ 独立侧栏（AI 助手：不阻塞游戏，连状态机都不进）。新功能先归类再动手。

## Information Architecture

### 顶层导航（首屏 title 态）

首屏是一个纵向排列的单列（`#start-screen`，点击空白处=直接进当前世界）：

```
⛏ 我的世界（display 大标题）→「网页复刻版」副标题
[6 存档槽 2×3 网格]（有档=点击进入+✕删除；空槽=🏗️建造/⚔️生存开新）
[▶ 回到游戏]（仅当有当前世界时显示，通栏主行动）
[🏗️ 建造模式] [⚔️ 生存模式]（空世界开新或覆盖重开，重开需两次点击）
[💾 保存进度] [⚙️ 设置（音频/存档）] [🗺 关卡]（菜单动作行）
[键位说明 controls-info 文字墙] + 「🖱 点击空白处可直接进入当前世界」脉动提示
```

「🗺 关卡」是关卡生态唯一入口（裁决 D2）：浮层内置 ① 官方关卡区（🏰 置顶，随包 14 张，无删除钮）→ ② 模板区（⭐）→ ③ 本机卡片区（含 📝 草稿 / 仅本次会话 徽章）三段列表 + 底部动作行（✏️ 新建空白关卡 / ▶ 试玩当前世界 / 📥 导入关卡卡）。行内操作：▶ 进入·试玩、🎥 拍宣传片、✏️ 改副本·继续编辑·用作模板、⭐ 存为模板、✕ 删除（二次确认）。

### 游戏内信息架构

游戏内没有「页面」概念，只有模态与浮层。层级总表（z-index 阶梯 = 规范，新浮层插入而非另起）：

| 层 | z | 成员 | 性质 |
|---|---|---|---|
| 世界画布 | 1 | gameCanvas | 永在最底 |
| 游戏内 HUD | 10~25 | 准星 10 / 调试·提示 15 / 模式徽章 19 / 血·饿·氧·经验·手持 20 / 闯关条 25 | 无指针事件 |
| 互斥模态 | 30~90 | E 背包 30 / 「点击画面继续」提示 40 / 物品说明条 45 / 受伤红闪 50 / 关卡结算 60 / 答题·作者卡 60~62 / 死亡 90 | 由 setState 驱动（答题/作者卡为非暂停浮层标志驱动） |
| 全屏覆盖 | 100+ | 首屏 100 / 助手 FAB 105·侧栏 110 / 关卡列表 110 / 设置浮层 118 / 助手 toast 120 | 独立挂载 |

## Voice and Tone

品牌语气：**对孩子的鼓励式短句，对家长的诚实说明**。文案规则：emoji 开头定情绪 → 一句话说清「发生了什么/下一步做什么」→ 绝不评判、绝不施压。被拒绝的操作必须自带理由（守卫提示），从不静默。

| 场景 | 用（现状实录） | 不用 |
|---|---|---|
| 闯关禁用操作 | 「🎒 闯关中不能打开物品栏」「🕊️ 闯关中不能飞行」 | 静默忽略；「Error: action blocked」 |
| 能力不存在 | 「⚠️ 只有建造模式才能飞行（按 M 切换）」 | 「此功能不可用」 |
| 星辉门答错 | 「💭 这个还没学哦——想要提前解锁吗？找 🤖 要个提示，或练完这周回来。」 | 「回答错误！正确答案是 X」 |
| 考核锁答错 | 「这扇门要靠你自己」（且不展示 hint） | 任何泄露答案倾向的提示 |
| 提前解锁 | 「🎉 提前解锁！这扇星辉门为你打开了」 | 「恭喜获得 10 积分」 |
| 存档失败 | 「⚠️ 存档失败：浏览器存储空间不足」 | 静默失败或笼统「出错了」 |
| 空关卡列表 | 「还没有关卡——✏️ 新建空白关卡用组件库搭一个，或让 🤖 帮你生成草稿」 | 「暂无数据」 |
| 空交接卡 | 「这周还没有带走的题。……打印出来，周末练完再回来开门。」 | 「本周错题 0 道（完成率 100%）」 |
| 学完全部单元 | 「……所有星辉门的知识点都在你手里了，去露一手吧！」 | 「课程进度 100%」 |

规则：**诚实降级也要诚实措辞**——题库未加载显示「题库加载中…」而非假装学完；IndexedDB 不可用给「仅本次会话」徽章并说明。对孩子隐藏复杂度（哈希/坐标/模式守卫一律翻译成人话），对家长摊开数据（学习页每张卡都有「全为本机聚合，不上传任何数据」式说明）。

## Component Patterns

行为规范（视觉见 DESIGN.md.Components）：

| 组件 | 出现处 | 行为规则 |
|---|---|---|
| 存档槽行 | 首屏 / 设置存档页 | 有档行点击=进入（先自动保存当前世界）；✕ 行内二次确认 4s 自动撤销；空槽行两钮开新。删除不可恢复必须二次确认 |
| 手持胶囊 | 游戏内常驻 | 只显当前手持；1-9/滚轮切换并弹物品名 tooltip；点击开 E 面板；F1 与主体一起隐藏 |
| HUD 状态条 | 生存模式 | 红心/鸡腿/气泡 emoji 条；只在数值变化时重绘；创造模式整体隐藏；气泡仅水下出现 |
| 闯关 HUD 条 | 闯关中 | 顶部居中 `mm:ss · 💀 n · 🔒 n/m`（时间金色等宽）；F1 可隐藏；闯关结束消失 |
| E 背包面板 | 生存/创造 | 生存顶部=配方列表（三站分组、缺料变红、点击即合成），下方=可搜索物品网格；点物品=选中并自动收起；搜索框聚焦时游戏键全部让路（isTypingTarget） |
| 物品说明条 | E 面板悬停 / 指针自由时 | 悬停即显、移开即隐；离开 inventory 态强制隐藏（display:none 不触发 mouseleave 的兜底） |
| 答题卡（玩家） | 右键答题机/锁 | 学科徽标+题型提示→数字输入（0..9999）或 1~4 选项；答错=抖动+hint+0.9s 后可重试（同格同题）；答对=卡片消失+门体翻转+音效 |
| 作者卡片（出题笔） | 手持出题笔右键答题机 | 自拟/抽题两页签；「🧮 算一算」系统算答案并回显；考核锁开关；保存后进入双通过试答（连对 2 次，答错清零）；作者走远/答题机被拆自动收卡 |
| 星辉卡 | 右键星辉门 | 超纲知识点标签 + 温和文案 + 错题入带走清单 + 引导找 🤖；考核锁换拒答文案 |
| 关卡行 | 「🗺 关卡」浮层 | 徽标体系（🏰/⭐/📝/仅本次会话）+ 最佳成绩星+时间 + 行内动作钮组；删除二次确认；官方卡无删除钮 |
| 结算浮层 | 踩终点/超时 | 只读面板：星级（3/2/1/0 超时失败）+ 用时/死亡 + 每锁答题明细滚动表；按钮 🔄 重试（重新嵌入、锁复位、成绩保留）/ 🚪 退出 / 📸 海报 / 🎥 宣传片；Esc=退出回首屏 |
| 导出面板（K） | 游戏内作者 | 校验状态行逐条提示；关卡名+昵称输入；「📤 导出并下载」/「💾 存进本机列表」；闯关中按 K 被守卫拒绝 |
| 组件库浮层（B） | 编辑器/创造 | 点选组件→准星瞄准左键盖章、右键/Esc 结束放置；面板打开时指针归面板 |
| 设置浮层 | 首屏/暂停 | 四页签记忆上次停留；滑块拖动即时生效并写 localStorage；只能从 title/pause 进入、关闭回原状态 |
| 交接卡 | 设置学习页 | 进度下拉（选中即写）→ 本周带走（学科分组、答案 details 折叠）→ 下周预告 → 回流 4 周简表 → 累计足迹 → 识字图鉴 → 重置（二次确认）；🖨 只印带走区且答案按当前折叠态印 |
| 助手侧栏 | 任意游戏态 | T/FAB 开关；打开时游戏键照常、鼠标归面板；Esc 弹暂停菜单但面板保持；会话/设置/新会话三钮头部；模型未配置显示「未配置」徽章 |
| 拍摄面板（Tab） | 游戏内 | 非暂停浮层：解锁鼠标但施工与录像继续；三种镜头直选；R 快捷开始/停止 |
| 死亡界面 | dead 态 | 保留背包文案安抚 + 「🔥 重生」实心绿主按钮；闯关中死亡走检查点重生（不弹此界面，计时不停） |

## State Patterns

### 模态状态机（uiModal.setState，互斥）

`title ⇄ playing ⇄ pause / inventory / settings / dead / result`

| 状态 | 进入 | 指针 | 退出 |
|---|---|---|---|
| title | 启动/退出关卡/退出编辑 | 自由 | 点槽位/模式/关卡卡 → playing 或对应流程 |
| playing | 期望锁定 | 锁定（失败→「🖱 点击画面继续」+1.3s 自动重试） | Esc/Q → pause；E → inventory；死亡 → dead |
| pause | Esc/Q 或指针被系统夺走 | 自由 | ▶/Esc/Q 回 playing |
| inventory | E（闯关禁） | 自由 | E/Esc/点选物品 → playing |
| settings | ⚙️（仅 title/pause 可进） | 自由 | Esc/Q/✕/点空白 → 回进入前状态 |
| dead | 玩家死亡 | 自由 | 🔥 重生 → playing |
| result | 踩终点/超时 | 自由（只读面板） | 🔄 重试=重新嵌入 / 🚪·Esc → title |

规则：任何状态切换都清空按键与鼠标按住态（防粘滞移动）；死亡时不可能回到 playing；迟到成功的指针锁请求不得抢回已被面板占用的鼠标。

### 非暂停浮层标志（游戏照跑，指针让位）

`recordingControlsOpen`(Tab) / `levelExportOpen`(K) / `prefabPickerOpen`(B) / `authorPanelOpen`(出题笔)——wantLockNow 与 isGameActive 同时检查这些标志；打开即 emit 同态事件清键；全部关闭自动走既有回锁链路。

### 数据与降级状态

| 状态 | 处理 | 用户感知 |
|---|---|---|
| 题库文件缺失/损坏 | 跳过该学科走内置兜底题 | 无感（玩法不阻塞）；全挂时星辉卡降级为一句话面板 |
| IndexedDB 不可用/超限 | 卡片降级会话内 | 列表行挂「仅本次会话」徽章 |
| 缩略图绘制失败 | 跳过图源 | 行布局照旧无图 |
| 存档配额不足 | 拒写并提示 | 「⚠️ 存档失败：浏览器存储空间不足」 |
| 存档尺寸不符（老档） | v4 自动迁移 | 无感（玩家改动零丢失） |
| 指针锁被拒 | 提示+自动重试 | 「🖱 点击画面继续」遮罩，1.3s 重试或点击即恢复 |
| 官方关卡清单缺失 | 空列表 | 官方区自然跳过，不报错 |

### 特殊状态

- **闯关模式**（levelRun）：全封锁守卫矩阵（见 Interaction Primitives）+ 正午锁 + 禁刷怪 + 饥饿氧气冻结（摔落保留）；存档防线拒写四通道（30s 自动/pagehide/隐藏/手动）；死亡=回最近激活检查点、计时不停、💀+1。
- **编辑器模式**（levelEdit）：强制创造+正午锁；允许挖掘放置与出题笔全流程；60s 静默自动存草稿、退出必存；顶部 HUD 条常显「✏️ 编辑中：{名}——B 打开组件库，K 完成导出」。
- **F1 隐藏 HUD**：body.hud-hidden 统一藏全部 HUD（截图/录屏用），再按恢复并提示。
- **窗口失焦/隐藏**：清键防漂移 + 兜底存档（闯关/编辑中被防线拒绝）。

## Interaction Primitives

**指针锁生命周期**（唯一管理者 uiModal）：playing 且无面板 → 期望锁定；用户 Esc（浏览器截获，页面收不到 keydown）或系统夺走指针 → 自动弹 pause；锁定失败（Chrome Esc 后 ~1.25s 冷却）→「点击画面继续」+ 1.3s 自动重试 + 任意点击立即重锁。**Q 是 Esc 的全功能替代键**（ZCode 内嵌浏览器中 Esc 会被宿主截获导致应用退出）：释放鼠标弹暂停、浮层里关闭、暂停/背包里回游戏，行为逐分支与 Esc 对齐——两键并在首屏键位表中。

**键盘模型**（input.js；焦点在输入框时全部让路）：

| 键 | 作用 | 守卫/备注 |
|---|---|---|
| WASD / Space / Shift / Ctrl | 移动/跳跃·双击飞行(创造)/潜行·下沉/疾跑 | 双击阈值 300ms；闯关双击空格被显式拒绝 |
| 左键 | 蓄力挖掘/攻击/组件盖章 | 编辑器放置态吞掉点击 |
| 右键 | 放置/进食/交互（工作台→门·TNT·拉杆→放置的优先级）/结束放置 | — |
| 中键 | 吸取方块 | 仅创造；挡浏览器自动滚动 |
| 滚轮 / 1-9 | 切换手持 | 自由摄像头时滚轮改为调速 |
| E / Z / F / M | 背包 / 丢弃 / 飞行(创造) / 换模式 | 闯关全部守卫拒绝并给理由 |
| F1/F2/F3/F5·V/F6 | 隐藏 HUD / 截图 / 调试 / 视角 / 昼夜(创造) | F5 preventDefault 防刷新 |
| Tab / R / C | 拍摄面板 / 录像 / 切镜头 | R 只认首次按下（防键盘自动重复连发录像） |
| B / K | 组件库 / 导出面板 | 闯关中 K 被拒 |
| [ ] / P / G | 施工调速 / 暂停 / 前往现场 | 除 title 外任何状态可用（AI 施工照跑） |
| T / Q / Esc | 助手 / Esc 替代 / Esc | 双轨制见上 |

**守卫模式（模式隔离的 UX 面）**：闯关/编辑的一切限制都是模式 guard，被拒操作**必须弹一条带 emoji 的理由 tooltip**（「🎒 闯关中不能打开物品栏」式），绝不静默失败；守卫文案矩阵与 E2E 用例（W11 全闭清单）一一对应。手感零污染：普通世界玩法与物理不受任何 guard 影响（NFR-6）。

**鼠标自由态**（面板打开）：点击画布=接管鼠标开始操作（面板保持打开）；作者面板打开时点击画布空白不抢指针（表单优先）。

## Accessibility Floor

现状（行为层）：
- **双编码**：一切状态 = emoji 图标 + 中文短句；颜色从不单独承载语义（耐久条绿→黄→红有位置渐进、答错有抖动+文案）。
- **准星 mix-blend-mode 反色**：任意背景下恒可见。
- **文字压图可读**：全量 text-shadow + 半透明底（DESIGN.md Elevation）。
- **操作可发现**：守卫拒绝必带提示；键位表常驻首屏；HUD 元素悬停/点击有说明（itemInfo 把数值规则翻译成人话）。
- **中文 locale**：`lang="zh-CN"`，全部界面与文案简体中文，年级语汇（三年级可读）。
- **危险动作防护**：删除/覆盖/清空一律二次确认，4s 冷却自动撤销（对误触友好的「撤销窗」）。

缺口（**【改进建议】**，未实现）：
- 无 `prefers-reduced-motion`（抖动/脉动/镜头动画无降级）；
- 键盘无法替代指针锁游戏操作（桌面键鼠为前提，属形态边界而非缺陷，但菜单层可低成本补 Tab 焦点样式）；
- 无读屏 aria 标注（画布游戏受益有限，浮层表单值得补）；
- `{colors.text-faint}` 级文字对比度未审计（见 DESIGN.md）；
- 触屏/手柄无任何映射（与移动端不支持声明一致，除非产品改裁决）。

## Key Flows

命名主角旅程（与 PRD UJ-1~UJ-5 同源，映射到表面与状态）：

### KF-1 小红导入关卡闯关攻城（消费者 · 主线）
1. 首屏（title）点「🗺 关卡」→ 浮层列出 🏰 官方区与本机卡片；2. 「📥 导入关卡卡」选同学的 `.level.json` → 校验通过，列表出现新行（缩略图+锁数）；3. 点「▶ 进入」→ **进关前当前世界强制落盘**（孩子无感）→ 临时世界嵌入、出生在起点旗、闯关 HUD 条亮起（计时开始）；4. 途中答题机=绿卡答题（1~4 选项/数字输入），答错抖动+hint，掉岩浆=回检查点、💀+1、计时不停；5. **高潮**：踩 🏁 终点旗 → 结算浮层弹出：★★★ 星级动画、用时/死亡、每锁答题明细滚动表；6. 🔄 重试刷星 / 📸 生成海报 / 🎥 拍宣传片 / 🚪 退出 → 世界精确恢复进关前模样。潜规则（孩子不需要知道但系统保证）：闯关中挖掘/背包/飞行全部被守卫拦下并解释；任何存档通道都写不进她的槽位。

### KF-2 小明出题、双通过、导出发布（作者位）
1. 在自家世界摆旗组与答题机；2. 手持 ✏️ 出题笔右键答题机 → 金色作者卡片：自拟算式（「🧮 算一算」系统算答案回显）或按学科+单元抽题，打开考核锁开关；3. 保存后以玩家视角**连过自己两次**（答错清零重计）；4. 重复给每把锁出题；5. **高潮**：按 K → 导出面板全绿 → 填关卡名+昵称 → 「📤 导出并下载」→ `小明的火焰地牢.level.json` 落盘，发班级微信群；6. 未双通过/选项重复时导出被拒并逐条提示，回卡片改题即可（草稿不受限，正式导出才拦）。旁路：先「▶ 试玩当前世界」再发布。

### KF-3 小明被星辉门钓走又练回来（回流）
1. 自家世界发现星辉门 → 右键弹出超纲题（卡上标「超纲知识点：第 N 单元」）；2. 答错 → 温和文案「💭 这个还没学哦……」+ 题目自动进错题本；3. 找 🤖 要梯度提示（先反问→方法→问是否更直接）；4. 周末按家长打印的带走清单纸面练完；5. **高潮**：回来再答 → 答对，门体翻转 + 「🎉 提前解锁！」+ 回流被端内记录；6. ⚙️「📚 学习」页回流趋势表 +1。

### KF-4 明妈用交接卡陪练（家长）
1. 打开 ⚙️ 设置 →「📚 学习」页签（记住上次停留）；2. 先把「学到」下拉拨到孩子最近单元（星辉门从这之后出题）；3. 「🧳 本周带走」：错题按学科分组，答案与提示默认折叠；4. **高潮**：点「🖨 打印交接卡」→ 只印带走区、白底黑字、答案按当前折叠态决定是否带上 → 拿纸陪练 20 分钟；5. 顺手看「📈 回流趋势」近 4 周两行小表——是交接不是监控，没有时长报表。

### KF-5 王老师办周五关卡日（教师）
1. 用 KF-2 流程造考核关（考核锁=冻结 AI 提示）；2. 收全班关卡卡文件；3. 课上学生互相导入攻城（KF-1）；4. **高潮**：学生对考核锁求助 → 助手明确拒答「这扇门要靠你自己」；5. 课后把各学生海报贴墙——排行榜排的是关卡，不是答题分。

### KF-6 新玩家第一局（冷启动）
1. 打开网址 → 首屏 6 槽网格（5 空 1 示例）→ 点空槽「🏗️ 建造」→ 直接进入世界（无教程弹窗，键位表常驻首屏可回看）；2. 生存开局自动附赠工具三件+苹果+原木（绿色提示行告诉玩家怎么活过第一夜）。

## 双受众切换（孩子面 / 家长面）

mcweb 的界面按受众切成两个互不渗透的面：
- **孩子面（默认）**：游戏 HUD、答题卡、关卡浮层、编辑器、助手——emoji 驱动、零专业术语、所有数字翻译成人话（「应力 80 超了水车 64」这类机关数值仅在准星提示按需出现）。孩子面里**从不出现**「正确率/时长/排名」类评价性数字（答题正确率只出现在家长面）。
- **家长面（⚙️「📚 学习」页）**：唯一出现统计的表面，且按「交接卡」而非「监控报表」组织——分组清单、折叠答案、打印出口、每张卡附「全为本机聚合，不上传任何数据」诚实说明。
- 切换成本刻意为零（同一个 ⚙️ 浮层里的一个页签），因为实际操作者常是孩子自己把设备递给家长；但内容语气完全分叉。**【改进建议】**（E9）低段家庭可加「家长面入门一句话」浮层；若 OQ-1/FR-41 裁决通过，家长面追加「⬇ 导出统计」按钮（聚合数字文件、自愿线下回传），是唯一允许的新增家长面表面。
