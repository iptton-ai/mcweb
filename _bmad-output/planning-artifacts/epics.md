# game（mcweb「我的世界 - 网页复刻版」）- Epic Breakdown

## 概述

本文档提供 mcweb 平台的完整史诗与故事分解，把 PRD（FR-1..42 / NFR-1..10 / E1..E11）、架构脊线（15 条 AD + 14 条承重不变量）与 UX 双脊线（DESIGN.md / EXPERIENCE.md，P1~P12 痛点）分解为可追溯、可验收的故事。因产品为**已上线存量项目**，故事分两类：

- **回溯性故事（Epic 1~7，对应 PRD E1~E7）**：描述**已交付**的能力与验收标准，验收锚点直接挂既有测试资产（`tests/e2e/run_*.py` / `smoke_*.py`、`tools/test_*.mjs`、`tools/validate_banks.py`），状态标 **Done**。其价值是建立「需求 → 故事 → 测试」追踪链：任何后续修改必须保持锚点通过（回归约束）；无测试锚点的 FR 如实标注「测试缺口」——宁缺勿假。
- **前瞻故事（Epic 8~11，对应 PRD E8~E11）**：状态标 **Backlog**，只写验收标准（AC）与架构约束（引用 AD 编号），**不写实现方案**；每项实施前须按 docs/create-lite-org-plan.md 流水线立项（G1 方案 → G2 对抗评审 → 开发 → G3 验收）。Epic 11 为条件需求，仅在对应开放问题（OQ-1/OQ-2）裁决为「是」时生效。

故事验收风格对齐仓库既有验收文化（G0 修复门 → G3 冻结清单验收；性能门「无数字的门等于没有门」；守卫拒绝必带理由文案）。

## 需求清单

### 功能需求（Functional Requirements，PRD §4，编号全局稳定）

> 标注〔现役〕= 已交付（回溯登记）；标注〔前瞻〕= 已定纲未排期。完整表述以 PRD 为准，此处为追踪用一行摘要。

- **FR-1**〔现役〕双模式体素世界：256×256×128 创造/生存，昼夜循环与动态 BGM；世界尺寸变更老档自动迁移、玩家改动零丢失
- **FR-2**〔现役〕生存成长线：29 条配方三站合成、四档工具（速度 2/4/6/8）、矿石采集门槛、饥饿/氧气/经验
- **FR-3**〔现役〕红石组：源 15 级→粉每格 -1，火把反相器/时钟、按钮 1s、压力板、灯 6 邻充能
- **FR-4**〔现役〕活塞组与粘液块：边沿驱动 0.15s 延迟、推动上限 12、粘液拖拽、弹跳（≥3 格/s 保留 80%）、实体载运、观察者 0.2s 脉冲
- **FR-5**〔现役〕动力组与物流组（Create-lite）：水车 8 RPM+64 SU、轴 1:1、齿轮换向、过载停转；传送带 1.5 格/s、投料器 0.5s、离合器
- **FR-6**〔现役〕滑轮电梯族：顶举/垂挂自动绑绳 ≤32 格、卷绳/放绳、1.5 格/s 载运、断水/过载/离合断开悬停、应力 32/台+8/格
- **FR-7**〔现役〕多槽存档与迁移：6 槽 localStorage RLE、30s 自动存+隐藏兜底、文件导出导入、v4 尺寸迁移、切槽清施工队列
- **FR-8**〔现役〕录像与拍摄系统：H.264+AAC mp4（降级链到 webm）、≤10 分钟、自动下载、三镜头切换不断录、recOwner 所有权
- **FR-9**〔现役〕多学科答题机：格子哈希同格同题（math 权重 2）、数字/选择题两题型、答错 hint、缺题库降级兜底、答对翻转常供能红石源
- **FR-10**〔现役〕题库契约与内容质量：契约 schema（input 0..9999/choice 互异/unit+hint 必带）、四学科覆盖、答案事实正确、UTF-8 无 BOM
- **FR-11**〔现役〕英语商人：三模式轮换（词:句=2:1）、答对奖励、en 词表唯一、句子图鉴 `s:` 前缀
- **FR-12**〔现役〕识字矿石与图鉴：~1% 生成、格哈希认领 258 字、注音+组词悬停
- **FR-13**〔现役〕星辉门预告锁：按学习进度出超纲题、答对开门+记提前解锁/回流、答错入错题本+引导找助手、考核锁改拒答
- **FR-14**〔现役·冻结〕奖励梯队维持现状不加码不扩散；去留待 OQ-4
- **FR-15**〔现役〕出题笔与作者面板：自拟（系统算答案回显）/抽题、考核锁开关、不持笔=玩家答题不变
- **FR-16**〔现役〕双通过发布门槛：每锁 verifiedPasses≥2、选项互异、答案合法、旗存在、BFS 不可达仅 warning；草稿豁免、正式导出拦截

### 非功能需求（NonFunctional Requirements，PRD §5）

- **NFR-1** 纯静态部署红线：无后端/无构建/零运行时依赖；公网必禁写文件接口；HTTPS 上游必须 HTTPS；纯静态托管下助手自动降级
- **NFR-2** 发版与缓存策略：HTML/JS/CSS no-cache（ETag 304）、媒体 1 小时；本地 server.py `Cache-Control: no-store`
- **NFR-3** 零数据采集与未成年人合规：无账号/无上报/无 SDK；Key 不出本机；家长可见性只经交接卡
- **NFR-4** 性能预算：每帧各子系统有界；红石 ≤4.3ms/动力 ≤2.5ms/电梯跨格零重算/工坊导入 ≤3000ms（W08）；扩容前先还元件索引债
- **NFR-5** 存储预算与降级：localStorage 6×~880KB 逼近配额，新增持久数据优先 IndexedDB；降级会话内+明确提示
- **NFR-6** 模式隔离手感零污染：闯关/编辑限制全是模式 guard，playerPhysics 零改动
- **NFR-7** 内容与资产优雅降级：题库/贴图/音效/BGM/编码/海报/清单七条降级链，缺文件不报错玩法不阻塞
- **NFR-8** 确定性与可测试性：worldSeed/生成器/抽题三重确定性；纯逻辑模块 Node 直测禁 three/DOM；每期上线前全套件回归
- **NFR-9** 平台兼容：现代桌面 Chrome 系开箱即玩；Three.js 0.160.0 CDN；键位避开浏览器默认快捷键
- **NFR-10** IP 与内容合规：命名避商标；课本内容只提取不受保护部分、不大段抄课文

### 附加需求（来自架构脊线 ARCHITECTURE-SPINE.md）

> 承重不变量速查（新代码检查单），故事的 AC 与技术注意点按编号引用：

- **AR-1**（AD-1）不引入构建工具/包管理器/运行时第三方依赖；入口 HTML 固定 index.html
- **AR-2**（AD-2）跨模块可变状态先进 `state.js`，不建私有状态仓
- **AR-3**（AD-3）调参与配方只改 `config.js`，消费方不复制数值
- **AR-4**（AD-4）新有状态方块：状态编进 ID + 派生态走运行时 Map + 全套登记（BlockInfo/outline/tile/isPropBlock/getPropMesh/pickBlockItem）；ID 段位先查段位表
- **AR-5**（AD-5）redstone.js else-if 链禁延长；网络求解走「事件 → 全量重算」骨架；锁具翻转唯一合法接线 = setBlockSafe + rebuildChunk + updateRedstoneNetwork
- **AR-6**（AD-6）切世界/进关必 `clearBuildQueue()`；助手批量建造只经 buildQueue 分帧
- **AR-7**（AD-7）存档版本化 + RLE + 存储分流：新持久数据优先 IndexedDB，localStorage 只进 <100KB 小体积；扩容前必还「种子+差分存档」债
- **AR-8**（AD-8）卡 schema 冻结只增不改；卡内一律局部坐标，world⇄local 只经 levelWorkshop；题目全量拷贝；validateLevelCard 是发布唯一闸门
- **AR-9**（AD-9）闯关/编辑限制一律模式 guard；写槽位只经 saveGame() 入口闸；唯一防线必须穷举失效前提；被拒操作必带理由文案
- **AR-10**（AD-10）指针锁只有 uiModal 调；新浮层先归类（互斥模态/登记标志/独立侧栏）并插入 z 阶梯
- **AR-11**（AD-11）助手与游戏本体解耦：boot 零依赖引导、非阻塞侧栏、热重载快照只落标记恢复侧放弃；提示词绝不代答
- **AR-12**（AD-12）确定性三地基：worldSeed / 生成器禁手改 JSON / 格子哈希同格同题
- **AR-13**（AD-13）双服务器接口等价：新增 /api 路由双实现同步或明确标注仅本机开发
- **AR-14**（AD-14）公网必禁写文件接口、缓存策略不得回退、零遥测；唯一允许出数通道=家长页一键导出文件（FR-41 条件）
- **AR-15**（AD-15）内容/代码接口契约化：题库唯一接口=edu-quiz-banks-contract.md + validate_banks.py 执行；工坊唯一事实源=edu-workshop-impl-contract.md；E2E 冻结清单只增不改
- **AR-16**（流水线文化）新批次一律走 G1 方案 → G2 对抗评审 → 开发 → G3 验收；commit 独立可 revert 且写明验证方式；新增性能分支先跑基线再定阈值（基线 ×1.2）
- **AR-17**（可测性边界）需 Node 直测的模块禁静态 import three/DOM/chunk；浏览器专用路径动态 `import()`；E2E 复用 lib.py 驱动库禁止裸写 sleep

### UX 设计需求（UX Design Requirements，DESIGN.md + EXPERIENCE.md）

> UX-DR1~6 为已实现现状（回溯 AC 来源）；UX-DR7~16 为【改进建议】（对齐 E8~E11 前瞻方向）。

- **UX-DR1**〔现状〕浮层显隐与指针锁唯一管理者是 uiModal；新浮层先归类（互斥模态/非暂停浮层标志/独立侧栏）再动手并插入 z 阶梯
- **UX-DR2**〔现状〕守卫拒绝必须弹带 emoji 的理由 tooltip，绝不静默；被拒操作与 E2E 用例（W11 全闭清单）一一对应
- **UX-DR3**〔现状〕无障碍底线：状态双编码（emoji+文字）、颜色不单独承载语义、准星反色恒可见、全量 text-shadow 压图可读
- **UX-DR4**〔现状〕危险动作（删档/覆盖/清空/重开）一律行内二次确认 + 4s 冷却自动撤销，不用系统 confirm/alert
- **UX-DR5**〔现状〕诚实降级措辞：「题库加载中…」「仅本次会话」徽章、空态手写文案、存档失败明示原因
- **UX-DR6**〔现状〕孩子面/家长面分离：评价性数字（正确率/时长/排名）只出现在家长面「📚 学习」页，且按交接卡而非监控报表组织
- **UX-DR7**〔前瞻·E9〕次要文字对比度 WCAG 审计并给 text-faint 定下限（DESIGN OQ-D1）
- **UX-DR8**〔前瞻·UI 批次〕补 `prefers-reduced-motion` 降级（答错抖动/首屏脉动/镜头动画）（P5）
- **UX-DR9**〔前瞻·E9〕低段「大字模式」档位：`body.grade-low` 类覆盖 token，正文 16px/按钮 +2px（OQ-E2 待裁决全局还是限级）
- **UX-DR10**〔前瞻·E10〕关卡列表升级「工具栏 + 分组列表」三段式（学段/学科/难度筛选 + N≤50 提示 + 排序）（P7）
- **UX-DR11**〔前瞻·E10〕学习页进度选择器升级「版本→学段→单元」分组选择（P8）
- **UX-DR12**〔前瞻·E8〕新锁具表面四件套缺一不收：作者面板题型扩展 + 组件库 + itemInfo 说明 + 守卫文案矩阵（P9）
- **UX-DR13**〔前瞻·E9〕高段约束报表面板：kineticStatusAt 数据复用（P10）
- **UX-DR14**〔前瞻·E11 条件〕家长面「⬇ 导出统计」按钮：聚合数字文件、自愿线下回传（P12）
- **UX-DR15**〔前瞻·E11 条件〕改名先出「文案资产清单」再替换；格式字符串不动（P11）
- **UX-DR16**〔前瞻·E9〕首屏键位墙折叠为「新手三步」卡或首局 3 步内嵌提示；形态须经 SM-5 儿童测试验证（P2）
